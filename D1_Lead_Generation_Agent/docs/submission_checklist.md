# D1 Submission Checklist

## Application
- [ ] Streamlit application runs
- [ ] ICP intake works
- [ ] Discovery works or mock fallback works
- [ ] robots.txt gate is visible
- [ ] Enrichment works
- [ ] Deduplication works
- [ ] Scoring and reasoning are visible
- [ ] CSV export works
- [ ] HubSpot-style export works
- [ ] Refresh/re-run works

## Evidence
- [ ] Architecture diagram
- [ ] Prompt documentation
- [ ] Screenshots
- [ ] Demo video
- [ ] README
- [ ] Public application link if required by the hackathon

## Security
- [ ] `.env` is in `.gitignore`
- [ ] API keys are not in code
- [ ] No private personal data is collected
- [ ] Only public business information is used
